# Neffto Solution - Office Admin & Blog Studio

A modern, responsive, full-featured Admin CMS for publishing, editing, and managing blog articles with direct Cloudinary CDN asset hosting and MongoDB Atlas persistence.

## Features
- **Modern Dashboard**: Real-time KPI statistics, live search, category filtering, and status toggle.
- **Blog Publishing Studio**:
  - Direct Drag & Drop / File Upload to Cloudinary CDN for both Cover Image and Author Avatar.
  - Interactive auto-slug generator with URL preview.
  - Category taxonomy and interactive tag chips manager.
  - Rich Markdown formatting toolbar.
  - Responsive workspace: Write Only, Split Screen, and Full Simulation.
  - Real-time word counter and read-time calculation.
  - Google SERP Snippet Preview & SEO meta tools.
- **Security**: Protected routes with session authentication (Default key: neffto@admin2026).
